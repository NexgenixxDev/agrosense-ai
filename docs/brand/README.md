# AgroSense logo

"Leaf scan": a leaf inside camera corners with an AI sparkle.

- `logo.svg` — the full icon (mint rounded tile). Used for the portal, favicon and in-app logo.
- `logo-foreground.svg` — the same drawing without the tile, for Android adaptive icons
  (background colour `#D5F5E3`). The drawing fills about 57% of the canvas, inside Android's
  safe zone, so no launcher mask cuts it off.

Colours: mint `#D5F5E3`, leaf `#2FA36B`, dark leaf `#1E7A4F`, sparkle `#FFC93C`.
Android PNGs are rendered from these files with headless Chrome.
